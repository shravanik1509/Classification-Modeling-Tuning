# Supervised Classification / Regression Modeling & Tuning

Task 3 project covering model comparison, hyperparameter optimization, evaluation, and model serialization.

## Models
- Logistic Regression
- Random Forest
- Gradient Boosting
- XGBoost

## Methods
- Stratified 5-fold cross-validation
- GridSearchCV
- Precision, Recall, F1-score
- ROC-AUC and ROC curves
- Confusion matrix
- Serialized champion model with Joblib

## Dataset
Breast Cancer Wisconsin Diagnostic dataset bundled with scikit-learn: 569 rows and 30 numerical predictors.

Open `notebooks/03_classification_modeling_tuning.ipynb` in VS Code/Jupyter and run cells in order.
